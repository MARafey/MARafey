## 🧩 The Software Engineer — My Claude Code Plugin

> **One command that runs the entire software development lifecycle.**

I built [**The Software Engineer**](https://github.com/MARafey/The-Software-Engineer) — a multi-agent system shipped as a **Claude Code plugin** (the `/software-engineer` command) and a **cross-IDE MCP server** for Cursor, Windsurf, VS Code, and any MCP-capable editor.

One command chains every agent in sequence: **requirements spec → database schema → backend routes → frontend components → Postman tests → simplification pass → contract validation → security scan → git commit → post-release SRE review** that feeds the next cycle. Each agent has its own SQLite knowledge base and Obsidian vault that grows smarter with every session.

```bash
# In Claude Code:
/plugin marketplace add MARafey/The-Software-Engineer
/plugin install software-engineer@software-engineer

# Then just describe what you want:
/software-engineer add user authentication with JWT and refresh tokens
```

✨ **Highlights:**
- 💬 Asks plain-language clarifying questions *before* writing code — shows its recommendation for every decision
- 🔍 Deep codebase scan on first use — routes, schema, conventions, security posture — loaded into every future session
- 🕸️ Builds an Obsidian code knowledge graph of your project
- 🔌 Same orchestrator exposed as an MCP server, so it works far beyond Claude Code
